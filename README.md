📱 iPhone Performance & Analytics Dashboard

📌 About the Project

**live demo** (https://iphone-dashboard-ram.streamlit.app)

This project is an interactive dashboard built using Python, Pandas, Plotly, and Streamlit to analyze iPhone product data from Flipkart.

It helps users explore iPhone prices, discounts, customer ratings, and review counts through interactive visualizations.

🚀 Features

- Filter products by brand
- View total iPhones listed
- Calculate average sale price
- Analyze average star ratings
- Display the top 10 highest-rated iPhones
- Explore price, ratings, and discount relationships
- View the raw dataset

🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

📂 Project Files

- "app.py" — Main dashboard application
- "apple_products.csv" — Dataset
- "requirements.txt" — Required Python libraries
- "README.md" — Project documentation

⚙️ Installation and Setup

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:
   
   cd iphone-analytics-dashboard

3. Install the required libraries:
   
   pip install -r requirements.txt

4. Run the application:
   
   streamlit run app.py

5. Open the local URL shown in your terminal.
